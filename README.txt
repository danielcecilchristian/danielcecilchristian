DANIEL CECIL CHRISTIAN — PORTFOLIO WEBSITE

HOW TO ADD YOUR 22 IMAGES
1. Put your exact image files inside the "images" folder.
2. Keep the filenames exactly as provided. The website is already configured to use them.
3. Double-click index.html to preview the site in a browser.

IMPORTANT:
- The image files themselves were not included because they were not uploaded in this conversation. Add them to images/.
- "profile.jpg" is currently treated as a portfolio item. You can later use it as your About/profile photo if preferred.

VIDEO SECTION
The site includes a ready placeholder for a future video portfolio.
When you are ready, add MP4 files to the "videos" folder. The script.js file contains a clear place to add video entries and playable <video> cards.
